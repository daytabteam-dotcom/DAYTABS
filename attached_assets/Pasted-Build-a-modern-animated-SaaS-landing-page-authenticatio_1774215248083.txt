🔐 AUTHENTICATION (GOOGLE + EMAIL)

Implement:
- Email/password signup & login
- Google OAuth login

AUTH FLOW:

1. User clicks "Login" or "Sign Up"
2. Can choose:
   - Email/password
   - Continue with Google

3. After successful authentication:
   - Create or retrieve user in database
   - Generate JWT token

4. REDIRECT USER TO CORE APP:

- Use environment variable:
   CORE_APP_URL=https://your-core-app.com

- Redirect with token:
   https://your-core-app.com?token=USER_JWT

--------------------------------------------------

🔑 TOKEN HANDLING:

- Use JWT for authentication
- Token should include:
   - user_id
   - email

- Expiry: reasonable (e.g. 7 days)

- Secure handling:
   - Do NOT expose sensitive data
   - Prefer httpOnly cookies if same domain
   - Otherwise pass via URL for MVP

--------------------------------------------------
